# 2. HTML básico

## O que é HTML?

HTML significa HyperText Markup Language, ou Linguagem de
Marcação de HiperTexto.

Ele é utilizado para estruturar o conteúdo de páginas web.

O HTML utiliza elementos chamados de tags para indicar ao
navegador como o conteúdo deve ser organizado.

## Estrutura básica de uma página HTML

Uma página HTML possui uma estrutura básica.

Exemplo:

```html
<!DOCTYPE html>
<html>
<head>
    <title>Minha primeira página</title>
</head>
<body>

    <h1>Olá, mundo!</h1>

    <p>Esta é minha primeira página HTML.</p>

</body>
</html>

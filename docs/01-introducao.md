# 1. Introdução ao desenvolvimento web

## O que é desenvolvimento web?

Desenvolvimento web é a criação de páginas e aplicações que podem
ser acessadas por meio de navegadores.

Uma página web utiliza diferentes tecnologias para estruturar,
estilizar e adicionar comportamento ao conteúdo.

## HTML

HTML significa HyperText Markup Language.

Ele é utilizado para estruturar o conteúdo de uma página web.

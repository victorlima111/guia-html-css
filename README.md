# Guia Introdutório de HTML e CSS

## Objetivo

Este guia apresenta os conceitos fundamentais de HTML e CSS
para pessoas que estão iniciando no desenvolvimento web.

Ao final do guia, o estudante será capaz de compreender a
estrutura básica de uma página HTML e aplicar estilos simples
utilizando CSS.

## Público-alvo

Este guia é destinado a estudantes e iniciantes em desenvolvimento
web que possuem pouca ou nenhuma experiência com HTML e CSS.

## Pré-requisitos

- Conhecimentos básicos de informática
- Um navegador de internet
- Um editor de código
- Computador com acesso à internet

## Estrutura

O guia está dividido nos seguintes módulos:

1. Introdução ao desenvolvimento web
2. HTML básico
3. CSS básico
4. Exercícios práticos
5. Referências

## Como navegar

Recomenda-se seguir os módulos na ordem apresentada.

Cada módulo apresenta explicações, exemplos e atividades práticas
para reforçar o conteúdo estudado.

## Autoria

Projeto desenvolvido como atividade final integradora.
